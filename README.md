## ✏️ Yang Perlu Diganti di index.html

Cari dengan Ctrl+F dan ganti:

| Cari | Ganti dengan |
|------|-------------|
| `emailkamu@gmail.com` | Email kamu |
| `62NOMORKAMU` | Nomor WA tanpa 0 (contoh: 6281234567890) |
| `@usernamekamu` | Username Instagram |
| `github.com/salsabilla` | GitHub kamu |
| `linkedin.com/in/salsabilla` | LinkedIn kamu |
| `Nama Pengalaman Kamu` | Nama pengalamanmu |
| `Nama Sertifikat 1/2/3` | Nama sertifikatmu |

## 🏅 Cara Tambah Sertifikat

1. Taruh foto sertifikat ke `assets/certificates/cert-1.jpg`
2. Di `index.html`, cari `cert-card` dan update:
   - `cert-1.jpg` → nama file foto
   - `Nama Sertifikat 1` → nama sertifikat
   - `Penyelenggara` → nama lembaga
   - `2024` → tahun

## 💼 Cara Tambah Pengalaman

Duplikat blok `<div class="exp-card rv">` di section experience dan isi dengan datamu.

## 🚀 Deploy ke GitHub Pages

### Via VS Code:
1. Buka folder `portfolio/` di VS Code
2. Install extension: **GitHub Repositories**
3. Buat repo baru di github.com
4. Push semua file
5. Ke Settings → Pages → Source: main → Save
6. Live di `https://username.github.io/portfolio`

### Via GitHub Desktop:
1. File → Add Local Repository
2. Pilih folder `portfolio/`
3. Publish Repository
4. Aktifkan GitHub Pages di Settings
